## 🎨 Quick Workflow

### Tạo Design Mới
```
1. Home → Click Quick Start size
2. Editor mở → Add elements từ left sidebar
3. Click element → Edit properties ở right panel
4. Adjust zoom nếu cần
5. Download khi xong
```

### Mở Recent Design
```
1. Home → Tab "Recent designs"
2. Click vào design
3. Continue editing
```

### Add Elements
```
Text:     Click "Text" → Text xuất hiện
Elements: Click "Elements" → Choose shape
Photos:   Click "Photos" → Select image
```

### Edit Properties
```
1. Click element to select (purple ring appears)
2. Right panel shows properties
3. Edit values hoặc use sliders
4. Changes apply instantly
```

## 💡 Tips & Tricks

### 🎯 Selection
- **Click** element để select

## 🆘 Common Issues

### Issue: Element không select được
**Solution:** Click chính giữa element, tránh edges

### Issue: Properties panel không hiện
**Solution:** Phải select element trước

### Issue: Zoom quá xa/gần
**Solution:** Click "Fit" button để reset

### Issue: Cannot undo
**Solution:** Check history index (có thể đã ở đầu history)
