## 💡 **WORKFLOWS:**

### **Workflow 1: Tạo Campaign & Collect Data**

```
1. CREATE CAMPAIGN
   ↓
   Click "Create Campaign"
   Fill: Name, Description, Dates, Target
   Click "Save"
   
2. ADD SOURCES
   ↓
   Open Campaign Detail
   Go to "Sources" tab
   Click "Add Source"
   Fill: Name, URL, Type, Schedule
   
3. START COLLECTING
   ↓
   Open Source Detail
   Click "Start Crawl"
   Watch real-time progress
   
4. MONITOR PROGRESS
   ↓
   View charts & stats
   Check article status
   Track success rate
```

### **Workflow 2: Manage Existing Campaign**

```
1. VIEW CAMPAIGNS
   ↓
   Go to Crawler Management
   See all campaigns with stats
   
2. CHECK DETAILS
   ↓
   Click "View" on campaign
   See Overview tab with charts
   
3. MANAGE SOURCES
   ↓
   Switch to "Sources" tab
   Edit/Pause/Delete sources
   
4. REVIEW ARTICLES
   ↓
   Switch to "Articles" tab
   Filter by status
   Export if needed
```

### **Workflow 3: Monitor Single Source**

```
1. OPEN SOURCE
   ↓
   From Campaign Detail → Sources tab
   Click "View" on source
   
2. CHECK PERFORMANCE
   ↓
   View Overview tab
   See charts & metrics
   
3. CONTROL CRAWLING
   ↓
   Click "Start Crawl" to run now
   Click "Pause" to stop
   
4. REVIEW ARTICLES
   ↓
   Switch to Articles tab
   See all collected articles
   Filter & export
```
