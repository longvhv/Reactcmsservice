# Element Library - Hướng Dẫn Sử Dụng

## 📚 Tổng Quan

Element Library là thư viện các pre-made elements (phần tử có sẵn) giúp bạn tạo infographic nhanh hơn, giống như Canva. Thư viện bao gồm hơn 50+ elements chuyên nghiệp được phân loại theo danh mục.

## 🚀 Cách Sử Dụng

### Bước 1: Mở Element Library
1. Click vào tab **"Elements"** ở Right Panel (bên phải màn hình)
2. Icon: ⭐ Star

### Bước 2: Tìm Kiếm Element
1. Sử dụng **Search bar** ở đầu panel
2. Gõ tên element hoặc category (VD: "arrow", "social", "badge")
3. Click ✕ để xóa tìm kiếm

### Bước 3: Lọc Theo Category
1. Click vào các category buttons:
   - **All** - Tất cả elements
   - **Decorative** - Hình trang trí
   - **Social** - Mạng xã hội
   - **Business** - Kinh doanh
   - **Communication** - Giao tiếp
   - **UI** - Giao diện
   - **Arrows** - Mũi tên
   - **Doodles** - Vẽ tay
   - **Frames** - Khung

### Bước 4: Chọn Element
1. Click vào element bạn muốn
2. Element sẽ tự động thêm vào canvas
3. Element mới sẽ được chọn sẵn để bạn chỉnh sửa ngay

### Bước 5: Tùy Chỉnh Element
Sau khi thêm element, bạn có thể:
- **Di chuyển**: Kéo thả element
- **Resize**: Kéo góc để thay đổi kích thước
- **Xoay**: Dùng rotation handle
- **Đổi màu**: Trong Properties Panel
- **Thêm hiệu ứng**: Trong Effects Panel (shadows, gradients)

## 💡 Tips & Tricks

### 1. **Kết Hợp Elements**
- Kết hợp decorative shapes với text để tạo headers nổi bật
- Dùng arrows để hướng dẫn flow của infographic
- Kết hợp badges với numbers cho statistics

### 2. **Tùy Chỉnh Màu Sắc**
- Mỗi element có màu mặc định
- Đổi màu trong Properties Panel để match với brand colors
- Dùng gradients cho decorative shapes

### 3. **Layering**
- Dùng Layers Panel để sắp xếp elements
- Decorative shapes nên ở background layer
- Text và icons nên ở foreground

### 4. **Consistency**
- Chọn 1 style (VD: rounded shapes)
- Dùng consistent color palette
- Maintain spacing giữa elements

### 5. **Search Nhanh**
- "social" → Social media icons
- "arrow" → Arrow elements
- "badge" → Badges và ribbons
- "frame" → Picture frames

## ⌨️ Keyboard Shortcuts

Không có shortcuts riêng cho Element Library, nhưng sau khi thêm element:
- **Delete** - Xóa element
- **Ctrl/Cmd + D** - Duplicate element
- **Ctrl/Cmd + C/V** - Copy/Paste
- **Arrow keys** - Di chuyển chính xác

## 🔄 Workflow Gợi Ý

### Tạo Infographic Mới:
1. Chọn template từ Templates Panel
2. Thêm decorative shapes từ Element Library
3. Thêm text với custom font styles
4. Thêm icons và symbols
5. Apply effects (shadows, gradients)
6. Export

### Enhance Existing Design:
1. Mở Elements tab
2. Search "badge" cho highlights
3. Search "arrow" cho flow
4. Search "frame" cho emphasis
5. Adjust colors để match design
