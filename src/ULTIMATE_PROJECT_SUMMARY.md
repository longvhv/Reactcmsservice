## 🎯 **CATEGORY SYSTEM HIGHLIGHTS**

### **Core Concept:**
```
Category → Article Type (1:1 Binding)

Example:
┌─────────────────────────────────────┐
│ Technology News (news)              │
│ ├─ Web Development (news)           │
│ ├─ Mobile Apps (news)               │
│ └─ AI & ML (news)                   │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│ Video Tutorials (video)             │
│ ├─ React Tutorials (video)          │
│ └─ Vue Tutorials (video)            │
└─────────────────────────────────────┘
```

**Rule:** Tất cả articles trong một category phải cùng type!

### **Benefits:**
1. ✅ **Clear Organization** - Không lẫn lộn content types
2. ✅ **Better Performance** - Optimized queries
3. ✅ **Type Safety** - Validation at category level
4. ✅ **User Experience** - Clearer navigation
5. ✅ **SEO** - Better site structure

## 📖 **CATEGORY USAGE EXAMPLES**

### **Example 1: Create News Category**
```tsx
const newsCategory = {
  name: 'Technology News',
  slug: 'technology-news',
  articleType: 'news', // REQUIRED
  description: 'Latest technology news',
  parentId: null,
  icon: '💻',
  color: '#3B82F6',
  isActive: true,
  isPublic: true,
};
```

### **Example 2: Filter Categories by Type**
```tsx
<CategorySelector
  selectedIds={selectedCategories}
  onChange={setSelectedCategories}
  articleType="news" // Only news categories
  multiSelect={false}
/>
```

### **Example 3: Create Sub-category**
```tsx
const subCategory = {
  name: 'AI & Machine Learning',
  slug: 'ai-machine-learning',
  articleType: 'news', // Must match parent
  parentId: '1', // Technology News
  icon: '🤖',
  color: '#8B5CF6',
};
```
